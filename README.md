# KrPoker Offline Poker

完全离线的单机无限注德州扑克训练游戏。

## 运行

直接双击 `dist/index.html` 即可游玩。也可以在项目目录启动任意静态文件服务器，并访问 `dist/`。

## 代码结构

纯前端，零构建、零依赖。各模块按顺序加载并挂到 `window.KrPoker`，
唯一的可变状态集中在 `poker-state.js`，其余模块通过 `KrPoker.state` 读写。

| 文件 | 行数 | 职责 |
| --- | --- | --- |
| `dist/poker-core.js` | 342 | 引擎：牌型评估、胜率模拟、边池、盲注表。纯函数，不碰 DOM |
| `dist/poker-state.js` | 121 | 共享状态、DOM 引用、通用工具、锦标赛辅助 |
| `dist/poker-stats.js` | 65 | 训练数据读写与展示 |
| `dist/poker-ui.js` | 136 | 渲染、牌局记录、音效与触感 |
| `dist/poker-ai.js` | 299 | 人格生成、对手建模、街道计划、决策入口 |
| `dist/poker-table.js` | 416 | 发牌、行动、街道推进、摊牌结算 |
| `dist/game.js` | 161 | 入口：牌桌生命周期与事件绑定 |
| `dist/ai-worker.js` | 27 | 后台线程胜率模拟 |

加载顺序由 `dist/index.html` 底部的 `script` 标签决定，改动模块依赖时需同步更新。

## 已实现

- 1～8 名 AI 对手
- 每名 AI 入座时随机生成固定人格，离桌后才会重置
- 系统安全随机数洗牌，无控牌入口
- 标准牌型比较、盲注、加注、全下、主池与边池
- AI 胜率模拟、底池赔率、诈唬、慢玩和玩家行为适应
- 基于位置、下注尺度和历史行动的对手范围推断
- 完整 169 类起手牌矩阵，范围会随位置、加注次数和尺度动态收窄
- 跨翻牌、转牌和河牌延续的价值下注、慢玩、半诈唬与放弃计划
- **筹码深度感知：按有效筹码与 SPR 区分短码全下、标准码与深码控池**
- **多人底池收紧：价值门槛随对手数量提高，诈唬频率相应下调**
- 均衡策略结合针对性调整，会利用玩家弃牌、跟注和加注倾向
- 玩家筹码耗尽后可领取 2,000 救济筹码
- 本地长期训练数据：VPIP、PFR、摊牌胜率、位置盈亏
- 安卓后台线程胜率计算、横屏牌桌、震动反馈和退出确认
- 发牌、筹码投入、赢取底池动画，以及牌桌内实时 AI 思考速度切换
- 操作区实时显示玩家在当前一手中累计投入的筹码
- 完全本地运行，无账号、无网络请求

## 游戏模式

| 模式 | 盲注 | 淘汰 |
| --- | --- | --- |
| 现金局 | 固定，开局自选 | 破产 AI 自动补码，牌桌始终满员 |
| 锦标赛 | 每 12 手递增，第 36 手起加收前注 | 破产 AI 淘汰出局并记录名次，只剩你时夺冠 |

锦标赛盲注从 10 / 20 起步，依次为 15 / 25 / 50 / 75 / 100 / 150 / 200，
超出预设表后按每 14 手 1.35 倍继续递增。

## 快捷键

- `F`：弃牌
- `C`：过牌或跟注
- `R`：下注或加注

## Android 安装包

可安装 APK 位于项目根目录的 `KrPoker.apk`。安卓源代码和重复构建说明见 `ANDROID.md`。

## 验证

三个测试脚本用 macOS 自带的 JXA 运行，无需安装依赖：

```bash
osascript -l JavaScript scripts/engine-tests.jxa      # 规则与核心算法
osascript -l JavaScript scripts/smoke-test.jxa        # 界面渲染
osascript -l JavaScript scripts/simulation-test.jxa   # 无头对局模拟
```

- `engine-tests` 覆盖全部牌型、A2345 顺子、七张牌选优、牌堆唯一性、
  边池守恒、随机排列一致性、筹码深度归档、SPR、多人门槛、
  锦标赛盲注单调性与压力值。
- `smoke-test` 验证开桌后座位、公共牌与对手面板正常渲染，
  且 AI 人格参数不外泄。
- `simulation-test` 真实发牌并跑完整街道计划，验证决策链不抛错、
  牌桌筹码守恒、前注真实入池，以及被淘汰的 AI 不再重新入座。
